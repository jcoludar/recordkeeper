# paperwork.yaml — annotated examples

- `minimal.yaml` — the smallest useful configuration. One file rule, two
  frontmatter predicates. Start here.
- `multi-doc-consistency.yaml` — adds a cross-document consistency rule.
  Every finding mentioned in today's session log must also appear in a
  separate tracker file (`TECHNICAL_DEBT.md` in the example).

Copy whichever shape matches your project, then adapt.
